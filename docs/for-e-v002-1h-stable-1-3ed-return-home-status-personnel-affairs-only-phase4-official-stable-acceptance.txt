一、本次修正
1. 「返鄉狀況」不再共用卡片顏色分類結果判斷。
2. 只有 category 為「請假 / 會議 / 活動 / 外訓」（或舊稱「人員行務」），且實際 sub_type / schedule_type 細項為「返鄉」時，才視為返鄉狀況行程。
3. 服務行程、一般行程或其他類型，即使標題含「返鄉」，不顯示「返」狀況提示、不套返鄉整日狀況底色。
4. description、sub_type_note、customer_name 皆不參與返鄉狀況判斷。
5. 既有卡片顏色規則維持不變：類型、細項或標題本身含「返鄉」時，卡片顏色仍可依原本設定套色；只是不能觸發返鄉狀況提示。

二、驗收情境
A. category=請假 / 會議 / 活動 / 外訓，sub_type=返鄉：應顯示返鄉狀況提示與整日返鄉狀況背景。
B. category=請假 / 會議 / 活動 / 外訓，schedule_type=返鄉：應顯示返鄉狀況提示。
C. category=服務行程，title=創為 返鄉工人證件轉交：不得顯示「返」狀況提示，不得把日期格當返鄉整日狀況。
D. category=服務行程，description=工人返鄉：不得顯示返鄉狀況提示。
E. category=一般行程，title=返鄉資料整理：不得顯示返鄉狀況提示。
F. category=請假 / 會議 / 活動 / 外訓，sub_type=會議，title=返鄉人員討論：不得顯示返鄉狀況提示。
