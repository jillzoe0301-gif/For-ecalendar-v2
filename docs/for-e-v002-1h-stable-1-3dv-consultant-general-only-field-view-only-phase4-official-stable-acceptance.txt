正式 tag：official-v002-1h-stable-1-3dv
接續版本：V002-1H-stable-1-3du
階段：第四階段「統一人員顯示與指派邏輯」補充修正

一、顧問左側功能
1. 顧問左側只顯示：
   - 個人行程表
   - 行程總覽
   - 行程搜尋
   - 人員帳號
2. 不顯示「顏色設定」。
3. 其他角色原本的顏色設定權限不變。

二、顧問新增行程
1. 顧問在個人行程表、行程總覽按新增時，行程類別只顯示「一般行程」。
2. 不顯示一般記事、待辦事項、服務行程、提醒事項、請假／會議／活動／外訓、公務車保養、證件交付或其他類別。
3. 即使繞過畫面送出其他類別，儲存前仍會阻擋。

三、顧問修改行程
1. 顧問可修改自己或指定越雙語人員名下的「一般行程」。
2. 修改一般行程時，類別選單只顯示「一般行程」，不可轉換成其他類別。
3. 顧問查看服務行程、提醒事項、外務行程、會議室、請假／會議／活動／外訓、一般記事、待辦事項等其他行程時，不顯示「修改行程」。
4. 即使直接呼叫儲存流程，也會阻擋非一般行程。

四、外務行程唯讀
1. 顧問可在個人行程表、行程總覽、越雙語固定群組及行程搜尋查看外務行程。
2. 外務行程不顯示「修改行程」。
3. 不顯示或不允許：
   - 已送件／完成
   - 要補件
   - 送件異常
   - 取消／刪除
   - 外務日修改／刪除
4. 直接開啟外務修改流程或送出外務修改表單時，會顯示「顧問只能查看外務行程，不能修改外務行程」。

五、原有顧問功能保留
1. 行程總覽預設固定快速群組「越雙語」。
2. 顧問本人固定顯示在最上方。
3. 固定名單與排序不變：
   孫祥薇、范武薔薇、黃氏玄莊、賴黃娟、武俊平、吳氏何江、阮氏芳、阮氏璧、范紅筠。
4. 提醒事項仍維持唯讀。
5. 人員帳號只顯示顧問本人，可修改自己的密碼。
6. 1-3dt 的顧問角色資料庫 CHECK constraint 修正保留。

六、不應受影響
1. 管理員、主管、行政／海外、翻譯、外務／宿管／會計、一般職員權限維持不變。
2. 不修改 Supabase schema、正式行程資料、schedule_id、schedule_assignees、日期、週期或 localStorage 結構。
3. 不影響 LINE、提醒通知、統計、外務頁、會議室、服務紀錄單。
4. 第五階段「統一表單欄位設定」尚未開始。

1. node --check src/main.js 通過。
2. npm run build 通過後才可 commit／push。
3. GitHub main 推送成功。
4. tag official-v002-1h-stable-1-3dv 更新成功。
5. Vercel main Production deployment 顯示 Ready。
