一、本次需求
1. 顧問可以修改自己或指定越雙語人員的非提醒服務行程。
2. 顧問對服務行程只能使用「修改行程」。
3. 顧問不能將服務行程標記為「已完成」。
4. 顧問不能取消或刪除服務行程。
5. 提醒事項與外務行程仍維持唯讀。
6. 一般行程原有權限不因本次修正改變。

二、畫面驗收
1. 使用顧問帳號開啟一筆可修改的非提醒服務行程。
2. 行程明細應顯示「修改行程」。
3. 行程明細不應顯示「已完成」。
4. 行程明細不應顯示「取消行程」。
5. 明細提示應顯示：顧問只能修改此服務行程的內容與執行者，不能按已完成、取消或刪除。
6. 修改服務行程後可正常儲存，且類別仍固定為服務行程。

三、直接操作防護驗收
1. 即使從舊畫面或其他按鈕呼叫 completeSchedule，顧問仍會被阻擋。
2. 阻擋訊息：顧問只能修改服務行程，不能將服務行程標記為已完成。
3. 即使從舊畫面或其他按鈕呼叫 openCancelModal / cancelSchedule，顧問仍會被阻擋。
4. 阻擋訊息：顧問只能修改服務行程，不能取消或刪除服務行程。

四、既有規則回歸
1. 顧問新增行程仍只允許一般行程。
2. 顧問可修改一般行程與非提醒服務行程。
3. 顧問不能修改提醒事項。
4. 顧問不能修改外務行程。
5. 顧問左側仍只有：個人行程表、行程總覽、行程搜尋、人員帳號。
6. 越雙語固定群組、人員順序與本人置頂不變。
7. 其他角色原本的完成、取消與刪除權限不變。
